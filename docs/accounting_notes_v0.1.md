## 位置づけ

この文書はSC法人の暗号資産元帳運用に関する内部メモ。税務判断の正本ではない。最終判断は税理士確認を優先する。

## 確認したい論点

| 論点 | 現在の前提 | 確認先 |
|---|---|---|
| 譲渡原価 | 移動平均法を前提 | 税理士 |
| 期末評価 | 活発な市場がある暗号資産は時価評価の可能性 | 税理士 |
| DEX取引 | Swapを売却・取得に分解 | 税理士 |
| 手数料・ガス代 | 取引ごとにJPY換算して記録 | 税理士 |
| Airdrop / Claim | 取得時価・益金認識の扱いを個別確認 | 税理士 |
| Staking | 報酬認識時点と評価を確認 | 税理士 |
| Rug / Burn / 0評価 | 損金・評価損処理の可否を個別確認 | 税理士 |

## JPT元帳からの反省

| 問題 | SCでの対策 |
|---|---|
| 売買、送金、手数料、Claim、LP、NFT等が単一表で混在 | タブを分離し、取引区分を固定 |
| JPY換算根拠が後から追いにくい | 価格ソースタブと証憑IDを必須化 |
| Swapが1行で意味不明になりやすい | 売却行と取得行に分解 |
| 手数料・ガス代が原価や損益に混ざる | 数量とJPY換算額を別列管理 |
| 期末評価と実現損益が混ざる | 実現損益と期末評価を別タブ管理 |
