# SC暗号資産リサーチ・ルーティン v0.1

ページ作成日時：2026-08-02 10:19 JST
最終更新日時：2026-08-02 10:19 JST

## 目的

SC法人の暗号資産運用で、候補発見から取引前プラン作成までを毎回同じ順番で確認する。

この文書は「買う銘柄を探す」ためではなく、「買ってよい状態まで検証できた候補だけを残す」ための手順である。

## 基本原則

- CoinGecko、CoinMarketCap、Xは発見装置として使う。
- 売買判断は、出来高、材料、実需、リスク、取引前プランの確認後に限定する。
- 根拠が1つしかない候補は `Watch` までに留める。
- 損切り価格、利確価格、最大損失額を書けない候補は取引しない。
- 記録できない候補、証憑を残せない候補、税務処理が不明な候補は取引しない。

## 日次15分ルーティン

目的は候補発見だけ。ここで買わない。

| 順番 | 確認先 | 見るもの | 記録 |
|---:|---|---|---|
| 1 | BTC / ETH | 24h変動、急落、全体地合い | `市況ゲート` |
| 2 | CoinGecko Trending | 24h検索急増銘柄、カテゴリ | 候補名、順位、URL |
| 3 | CoinMarketCap Trending | 24hで可視性が高い銘柄 | 候補名、順位、URL |
| 4 | CoinMarketCap Gainers & Losers | 急騰・急落銘柄 | 候補名、変動率、出来高 |
| 5 | Xリスト | 公式発表、上場、提携、エアドロ、煽り増加 | 投稿URL、発信者 |
| 6 | 前日Watch | 継続材料、出来高変化、否定材料 | `継続` / `終了` |

### 日次ルーティンの終了条件

次のいずれかで終了してよい。

| 条件 | 対応 |
|---|---|
| BTC/ETHが大きく崩れている | 新規候補抽出のみ。取引前プランへ進めない |
| 候補がない | `候補なし` と記録して終了 |
| 候補が多すぎる | 最大5件だけ `Watch` に残す |
| 気分で買いたくなった | その時点で新規取引禁止 |

## 候補検証30分ルーティン

日次15分で残した `Watch` のうち、気になるものだけ確認する。

| 順番 | 見るもの | 合格条件 | 不合格例 |
|---:|---|---|---|
| 1 | 出来高 | 24h出来高が増えている、または出来高の水準が十分 | 価格だけ上昇、出来高が薄い |
| 2 | 材料 | 公式または準公式で確認できる | Xの煽りだけ |
| 3 | 上場/取扱 | CEX発表、取引所告知、公式告知 | 噂だけ |
| 4 | 実需 | TVL、Fees、Revenue、利用者数、オンチェーン活動 | 指標なし、雰囲気だけ |
| 5 | トークン設計 | FDV、流通量、アンロック、VC保有 | 直近大型アンロック、不明瞭な配分 |
| 6 | 流動性 | 国内取引所、CEX、DEX liquidity | Exitできない流動性 |
| 7 | 税務/記録 | Google Sheetに記録できる | 記録方法が分からない取引 |

## 情報源一覧

| 種類 | 主な確認先 | 用途 | 注意 |
|---|---|---|---|
| Trending | https://docs.coingecko.com/reference/trending-search | CoinGeckoの24h検索トレンド確認 | 人気化の検知であり買い根拠ではない |
| Trending | https://coinmarketcap.com/trending-cryptocurrencies/ | CMC上の可視性確認 | 煽りと混ざりやすい |
| Gainers/Losers | https://coinmarketcap.com/gainers-losers/ | 急騰・急落候補の検知 | 急騰後の追撃買いは禁止 |
| TVL | https://defillama.com/ | プロトコル規模確認 | ミーム銘柄には効かない場合あり |
| Fees/Revenue | https://defillama.com/fees | 実需・収益の確認 | 表示定義を確認する |
| 公式情報 | 公式X、公式Blog、Docs、Discord告知 | 材料の一次確認 | URLを必ず残す |
| リスク | Token Unlocks、公式トークノミクス、ブロックエクスプローラ | アンロック、権限、供給量確認 | 不明ならEntry不可 |

## ステータス分類

| ステータス | 意味 | 次の行動 |
|---|---|---|
| `Ignore` | 一過性、根拠薄い、触らない | 記録だけ残して終了 |
| `Watch` | 話題化あり。まだ根拠不足 | 翌日または数時間後に再確認 |
| `Research` | 材料あり。追加確認する | 30分検証へ進める |
| `Entry候補` | 条件を満たし、取引前プラン作成へ進める | `templates/trade_plan_template.md` を使う |
| `Rejected` | 明確な却下理由あり | 却下理由を残して終了 |
| `Closed` | 監視終了 | 再開する場合は新規ログにする |

## Entry候補への昇格条件

全て満たす場合だけ `Entry候補` にする。

| No | 条件 |
|---:|---|
| 1 | BTC/ETHが大きく崩れていない |
| 2 | 出来高が増えている、または十分な流動性がある |
| 3 | 公式または準公式の材料URLがある |
| 4 | ソースが1つだけではない |
| 5 | 直近の大型アンロックや重大リスクがない |
| 6 | JPY換算、取得原価、譲渡原価を記録できる |
| 7 | 取引所CSV、スクショ、Tx URLなど証憑を残せる |
| 8 | エントリー価格、損切り価格、利確価格を書ける |
| 9 | 最大損失額が10,000円以内 |

## 却下条件

1つでも該当したら `Rejected` にする。

| 条件 | 理由 |
|---|---|
| Xの熱狂だけ | Exit liquidityになりやすい |
| 出来高が薄い | 売れない、滑る |
| FDVだけ大きい | 希薄化・過大評価リスク |
| 大型アンロックが近い | 需給悪化リスク |
| 公式情報が見つからない | 材料の裏取り不可 |
| 記録方法が不明 | 会計元帳に載せられない |
| 税務処理が不明 | 税理士確認まで停止 |
| 損切りを書けない | 感情トレード化する |

## 取引前プランへの接続

`Entry候補` になったら、実際の取引前に必ず `templates/trade_plan_template.md` を作る。

取引前プランに最低限書くもの：

| 項目 | 内容 |
|---|---|
| 銘柄 | シンボル、正式名称、チェーン |
| 取引場所 | Coincheck / bitFlyer / MetaMask等 |
| 根拠 | 公式URL、データURL、出来高、材料 |
| Entry価格 | JPY併記 |
| 損切り価格 | JPY併記 |
| 利確価格 | JPY併記 |
| 最大損失額 | 10,000円以内 |
| 記録方法 | Google Sheetにどう入力するか |
| 証憑保存先 | Drive/Dropboxの保存先 |

## 運用メモ

- 日次ログは `templates/daily_research_log_template.md` を使う。
- 重要な調査だけ `records/research/` に残す。
- Notion DBを使う場合も、ルール変更・テンプレ・月次レビューの正本はGitHubに残す。
- APIキーが必要な有料APIは、このrepoにキーを書かない。
