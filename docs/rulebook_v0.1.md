# SC暗号資産運用ルールブック v0.1

ページ作成日時：2026-08-02 08:04 JST
最終更新日時：2026-08-02 08:04 JST

## 基本方針

SC法人の暗号資産運用は、短期アルト売買による運用実験として行う。資産形成の本体ではなく、明確な資金枠内の投機運用として扱う。

判断はルール優先。感情、焦り、Xの熱狂、損失回復欲求で売買しない。

## 資金枠

| 枠 | 金額 | 用途 |
|---|---:|---|
| 待機JPY | 500,000円 | 暴落時、税金、事故対応。原則触らない |
| 国内取引所枠 | 300,000円 | Coincheck / bitFlyerでの売買 |
| MetaMask枠 | 100,000円 | DEX、オンチェーン実験。最も危険な枠 |
| 予備枠 | 100,000円 | 手数料、送金、想定外対応 |

## 取引前の必須条件

全て満たす場合だけ取引する。

| No | 条件 |
|---:|---|
| 1 | BTC/ETHが大きく崩れていない |
| 2 | 対象銘柄の出来高が前日比で増えている |
| 3 | 上場、提携、エアドロ、TVL増、収益増、オンチェーン資金流入など理由がある |
| 4 | 直近に大きなトークンアンロックがない |
| 5 | エントリー価格、損切り価格、利確価格を先に記録した |
| 6 | 1回の最大損失が初期資金の1%以内、つまり10,000円以内 |
| 7 | Google Sheetに記録できる取引である |
| 8 | 証憑を保存できる取引である |

## 売買ルール

| 条件 | 行動 |
|---|---|
| -5%から-8%下落 | 損切り |
| +15%から+30%上昇 | 半分利確 |
| +50%以上急騰 | 段階利確。追撃買い禁止 |
| Xで熱狂・煽りが増える | 利確寄り |
| 買った理由が消えた | 即撤退 |
| 記録できない取引 | しない |
| 損切り条件を後から動かしたくなった | 新規取引停止。理由を記録 |

## Swapの扱い

Swapは1行で雑に記録しない。原則として次の2行に分解する。

| 行 | 内容 |
|---|---|
| 1 | 旧トークンの売却、または支出 |
| 2 | 新トークンの取得 |

これにより、JPY換算額、譲渡原価、実現損益、取得原価を後から追えるようにする。

## 禁止事項

- 損切りルールの先送り
- 記録前の追加買い
- 取引理由が「なんとなく」「熱い」「まだ行けそう」だけの取引
- 証憑が残らないDEX操作
- 秘密鍵、シード、APIキーをGitHubやNotionに記録すること
- JPT資金・個人資金との混在
- 正本ファイルのコピー乱立

## 運用停止条件

次のいずれかに該当したら、新規取引を止める。

| 条件 | 対応 |
|---|---|
| 元帳未記録の取引が3件以上ある | 記録完了まで新規取引停止 |
| 月次損失が初期資金の10%を超えた | 1週間停止し、ルール見直し |
| 税務処理が不明な取引が発生した | 税理士確認まで類似取引停止 |
| MetaMaskで不審な承認・送金がある | ウォレット隔離、証憑保存、原因確認 |
| 感情トレードが発生した | 操作停止、運用ログに記録 |
