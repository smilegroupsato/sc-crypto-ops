## 判断トレース

| 判断 | 理由 |
|---|---|
| `matrix.html` を追加 | 1画面Dashboardに長い採点表を入れ続けると運転席として重くなるため |
| `matrix.js` を分離 | 既存 `app.js` はDashboard DOMを前提にしており、別Pageで再利用すると不要なDOM参照で壊れやすいため |
| `data.json` を正本にする | 日次PDCAが1ファイルを更新すれば、DashboardとMatrix Pageの両方へ反映できるため |
| Dashboardにはナビ追加のみ | 既存の表示を壊さず、Page間移動だけ足すため |
| ログを `records/context_logs/` に置く | PDCAログ本体と区別し、作業文脈・取得物・判断過程をまとめるため |
| 内部推論を逐語記録しない | 非公開の内部推論・システム指示・秘匿情報を含み得るため。代替として判断トレースを記録する |
